# WebProgramming

## Описание проекта

Данный репозиторий содержит выполненные задания по курсу **Web Programming**.
Проект демонстрирует постепенное развитие веб-приложения: от простой статической веб-страницы до современного клиентского приложения с использованием **React** и интеграции с **Web API**.

В процессе работы последовательно осваиваются ключевые технологии веб-разработки и принципы построения интерактивных веб-интерфейсов.

---

## Этапы разработки

### HW1 — Статическая веб-страница

На первом этапе была реализована базовая веб-страница с использованием:

* **HTML** — для структуры и разметки страницы
* **CSS** — для стилизации и оформления интерфейса

Страница является **статической** и содержит только базовую структуру и оформление.
Страница создана по макету **Figma**: https://www.figma.com/design/sVv4aYKNZn3CCUjdnTN9jI/UCD-task?node-id=355-885

---

### HW2 — Добавление JavaScript

На втором этапе был добавлен **JavaScript**, что позволило:

* реализовать интерактивные элементы интерфейса
* обрабатывать действия пользователя
* динамически изменять содержимое страницы

В результате приложение стало **динамическим**.

---

### HW3 — Интеграция с Web API

Далее в проект было добавлено взаимодействие с **Web API**.

Это позволило:

* получать данные из внешних источников
* динамически отображать полученную информацию
* реализовать асинхронную загрузку данных

Таким образом приложение стало работать с **реальными внешними данными**.

---

### HW4 — Реализация приложения на React

На следующем этапе приложение было реализовано с использованием **React**.

В рамках этой работы:

* интерфейс был разделён на **компоненты**
* улучшена **структура и масштабируемость кода**
* реализовано **управление состоянием приложения**

Использование React позволило применить современные подходы к разработке пользовательских интерфейсов.

---

### Деплой приложения

На финальном этапе проект был **задеплоен**, что позволило развернуть приложение и сделать его доступным для пользователей через интернет.

---

## Используемые технологии

В ходе выполнения проекта использовались следующие технологии:

* **HTML5**
* **CSS3**
* **JavaScript**
* **Web API**
